\begin{resumo}[Abstract]
  \begin{otherlanguage*}{english}
    This work presents the planning and foundation of a controlled experiment designed to investigate the influence of prompt engineering patterns on the evaluation of the software maintainability indicator by Large Language Models (LLMs). Traditional static analysis tools are established for detecting syntactic violations but exhibit limitations when analyzing broader semantic and contextual aspects, such as maintainability, in addition to showing low mutual agreement. With the advancement of LLMs and prompt engineering techniques, the opportunity arises to apply these models to qualitative code analysis, although there is a lack of clarity on how their evaluations align with traditional quality models and to what extent instruction formulations influence the results. To address this gap, a structured literature review was initially conducted to map the state of the art of LLMs in software quality assurance, identifying reference models (SQALE, Q-Rapids, and MeasureSoftGram) and prompt patterns (zero-shot, few-shot, and chain-of-thought). Subsequently, a detailed plan for a technology-oriented controlled experiment was developed, structured around a Randomized Complete Block Design (RCBD) with composite blocks. The evaluated treatment factor corresponds to the three prompt patterns, with the measured maintainability indicator as the dependent variable, and the LLM tool used (ChatGPT, Claude, and DeepSeek) and the reference quality model as blocking variables. For validating measurement alignment, the SonarQube and MeasureSoftGram tools will be used as reference instruments applied to source code files from open-source web application repositories. The first stage of the work, documented in this monograph, consolidates the literature review and the statistical and operational modeling of the experiment, providing the necessary methodological foundations for its systematic execution and replication in TCC2.

  \end{otherlanguage*}
\end{resumo}
